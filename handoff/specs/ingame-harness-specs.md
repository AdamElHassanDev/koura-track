### `mc_probe.lua`, step by step
1. **Folder** (line 16): `ac.getFolder(ac.FolderID.ACDocuments) .. '/mapcreator_probe'`. Under Proton that should be `<pfx>/drive_c/users/steamuser/Documents/Assetto Corsa/mapcreator_probe/`.
2. **Timing constants:** `SETTLE_S = 1.2` (18), sim seconds after each teleport ("the car drops ~0.5 m"). `SHOT_HOLD_S = 0.5` (21).
3. **State `loading`** (86–90): `io.load(dir..'/points.json')`, then `JSON.parse`. It reads `points`, `quit` and `screenshots_every` (35–43; it ignores `yaw_deg`). It then writes `status.json` = `{state="starting", points=N, csp=ac.getPatchVersionCode()}`.
4. **State `starting`** (91–98): `if sim.isInMainMenu then ac.tryToStart(true) else state='probing'`. This presses Drive from inside the app.
5. **Teleport** (109–112), verbatim:
   ```lua
   -- CSP 0.2.11 faces the car *against* the direction it's given (M3, issue #14), so pass the
   -- reverse of the road's forward vector to face along the road.
   physics.setCarPosition(0, vec(p.pos), vec({ -p.dir[1], -p.dir[2], -p.dir[3] }))
   wait = SETTLE_S
   ```
6. **Measurements after settling** (`record`, 45–73):
   - For each wheel 0–3: `contact = wheel.contactPoint` (x, y, z), `valid_track = wheel.surfaceValidTrack`, `surface = wheel.surfaceSectionIndex`.
   - `wheels_outside = car.wheelsOutside`.
   - `raycast_m = physics.raycastTrack(car.position + vec3(0,20,0), vec3(0,-1,0), 60)`. A negative value means a miss.
   - `lateral`, `progress` = `ac.worldCoordinateToTrack(car.position)` `.x` and `.z` (59, 70–71). **This needs the AI spline.**
   - `fps = pcall(ac.getSim().fps)`, `i = index`, `requested = p.pos`, `position` (x, y, z).
7. **Screenshots** (118–121): `ac.makeScreenshot(dir..'/shot_'..index..'.png', ac.ScreenshotFormat.PNG)` when `(index-1) % screenshots_every == 0`, then hold for 0.5 s. The shot captures a later frame.
8. **Finish** (75–83):
   - `save('results.json', {results=..., csp=ac.getPatchVersionCode()})`.
   - `status.json` = `{state='done', points=N}`.
   - `io.deleteFile(dir..'/points.json')`. The comment: "os.remove is a stub inside CSP's sandbox".
   - `if options.quit then ac.shutdownAssettoCorsa() end`.
9. **Window** (129–132): shows the state and "point i of N".

Example `results.json`:
```json
{"csp":2xxx,"results":[{"fps":87.3,"i":1,"requested":[123.456,45.2,-678.9],
 "position":[123.41,44.71,-678.88],
 "wheels":[{"contact":[122.6,44.41,-677.5],"valid_track":true,"surface":0}, "...x4"],
 "wheels_outside":0,"raycast_m":20.3,"lateral":0.05,"progress":0.0123}]}
```

### What depends on the fast_lane spline, and must change for free roam
- **`mc_probe.lua` 59, 70–71:** `ac.worldCoordinateToTrack`. Remove it, or ignore its output.
- **`probe_points` (`ac_harness.py:338–357`):** the whole point generator reads `fast_lane.ai`. Replace it with your own road points and directions, at road height + ~1.0 m. `SETTLE_S`, the 1.0 m wheel-gap limit and the 3 m teleport tolerance all assume that drop.
- **`probe_report` 389–390:** the lateral check.
- **`watch_report`:** entirely spline-based (453–455).
- **`valid_track` caveat:** it reflects `surfaces.ini` `IS_VALID_TRACK`. mapcreator sets GRASS to 0, so a wheel on grass fails the check.

### `mc_watch` (manifest is the same layout; `SIZE = 320, 60`)
- **Switch:** active only if `dir..'/watch.on'` exists at load, and it deletes that file (10–14).
- **Sampling:** every 0.25 s for the first 15 s, then every 1 s (65). It rewrites `watch.json` every 5 s (67–69).
- **Schema:**
  ```
  {samples:[{t, fps, menu, cars:[{i, pos[3], look[3], kmh, spline, laps, ai, out, wheels:[{y, valid, load}], dmg[5]}]}], csp}
  ```
- `spline = c.splinePosition` (43) is read through `pcall` and is meaningless without an AI line; the rest works for free roam.

### Other checks
- **`ground_checks` / `ground_holes` (701–763), G and the most useful one for free roam:**

### KN5 version handling
- **mapcreator `core/kn5.py:280–286`:** accepts v5.
  ```python
  if r.take(6) != MAGIC: raise ValueError("not a KN5 file")
  version = r.i32()
  if version > 5:
      r.i32()
  ```
  - Any version is accepted, with the extra int read only when version > 5. It writes v6 by default (150, 164–165).
  - It rejects node class 3 (`raise ValueError(f"unknown node class {cls}")`, 322) and trailing bytes (328–329).
- **road-to-assetto `roadtoassetto/inspect_kn5.py:31–35`:** accepts only `version not in (5,6) -> ValueError`, then `if version>5: unpack('i')`. It rejects node kinds other than 1/2, more than 65,536 vertices per mesh, index count not divisible by 3, NaNs, samplers naming missing textures, depth over 100, and trailing bytes.
  - **No CLI.** It is a library function `inspect(path: Path, geometry=False)` that returns:
    ```
    {'version','textures':[names],'materials':[{name,shader,blend,alpha,depth,properties,samplers}],
     'meshes':[{name,vertices,triangles,material,cast_shadows,visible,renderable,lod_in,lod_out
                (+positions,normals,uv,tangents,indices if geometry)}],
     'markers':{AC_name: 4x4 list},'nodes':count,'bytes':size}
    ```
  - Callers: `scripts/validate.py:16` and `build.py:21`, among others.
- **openlaps `tools/kn5_inspect.py`:** usage `python tools/kn5_inspect.py pista.kn5 [--texturas carpeta] [--json salida.json] [--muestras N]` (5, 38–43).
  - Version: `ver = r.i(); extra = r.i() if ver > 5 else None` (46–47). Any version is accepted, v5 included.
  - It also handles class 3 skinned meshes (bones, 76-byte vertices, 105–113) and skips vertex data without loading it.
  - Output (Spanish):
    - `versión V extra E`
    - texture list with size, format, DDS dimensions/mips/fourcc
    - materials with shader, blend, alpha test, depth, props, samplers
    - first 80 dummies with matrix
    - mesh totals
    - groups by name with digits replaced by `#`
    - first 40 physics meshes
    - `leído hasta X de Y` (bytes read)
    - `--json` dumps `{textures, materials, dummies, meshes}`.
- **openlaps `tools/kn5_check.py`:** usage `python tools/kn5_check.py file.kn5`.
  - Version: `if ver > 5: r.i()` (36–38).
  - Asserts each texture is PNG or DDS and each sampler texture is embedded; only classes 1/2; indices in range; finite vertices; material ids valid; no trailing bytes.
  - Prints `KN5 OK: versión ..., N texturas, M materiales, mallas, vértices, triángulos`, physics meshes per KEY, and the `AC_` dummies.
